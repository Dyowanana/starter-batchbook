# Starter Batchbook

A quiz that turns your answers into a posting calendar. Every post comes planned with a hook, main point, format, how to make it, a CTA (when it fits), and film/edit time blocks.

Everything runs in the browser in one file, `index.html`. Nothing is saved to a server: the batchbook stays in your browser, so export it to Google Sheets or save it as a PDF.

## Edit it
- **Your handle / email form:** the `CONFIG` block near the top of the main script.
- **Hooks:** paste more into the `my-hooks` block, one per line.
